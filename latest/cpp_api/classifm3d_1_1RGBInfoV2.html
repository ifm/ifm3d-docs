std::uint32_t ifm3d::RGBInfoV2::rolling_shutter_row_offset_ns {}

Rolling-shutter offset between consecutive row timestamps, given in [nanoseconds].

The exposure-center timestamp of row y is t_row(y) = timestamp_ns + (2 * y - (height - 1)) * rolling_shutter_row_offset_ns / 2
